## Objective

Analyze the target application at {{WEB_URL}} for GraphQL-specific vulnerabilities. You have access to the source code and a live Playwright browser session ({{PLAYWRIGHT_SESSION}}).

Read the reconnaissance deliverable at `deliverables/recon_deliverable.md` and code analysis at `deliverables/code_analysis_deliverable.md` before starting.

## Methodology

### 1. GraphQL Endpoint Discovery
- Identify GraphQL endpoints (commonly /graphql, /api/graphql, /gql)
- Check for GraphQL IDE exposure (GraphiQL, Playground, Altair)
- Test for introspection query availability

### 2. Schema Analysis
- Run introspection queries to map the full schema
- Identify sensitive types, queries, and mutations
- Map authorization requirements for each operation

### 3. Query Complexity Attacks
- Test for missing query depth limits
- Test for missing query complexity limits
- Attempt resource-exhaustive queries (nested relations, circular references)
- Test batch query abuse

### 4. Authorization Testing
- Test for broken object-level authorization in queries
- Test mutation authorization bypass
- Test subscription authorization
- Check for IDOR through GraphQL resolvers

### 5. Injection Vectors
- Test for SQL injection through GraphQL variables
- Test for NoSQL injection in resolvers
- Test for SSRF through GraphQL federation or remote schema stitching

### 6. Information Disclosure
- Test for verbose error messages exposing internals
- Check for debug mode enabled
- Test for field suggestions leaking schema info
- Check for stack traces in error responses
