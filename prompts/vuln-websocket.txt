## Objective

Analyze the target application at {{WEB_URL}} for WebSocket-specific vulnerabilities. You have access to the source code and a live Playwright browser session ({{PLAYWRIGHT_SESSION}}).

Read the reconnaissance deliverable at `deliverables/recon_deliverable.md` and code analysis at `deliverables/code_analysis_deliverable.md` before starting.

Read `deliverables/shared_context.json` for accumulated knowledge from prior agents.

## Methodology

### 1. WebSocket Endpoint Discovery
- Identify WebSocket endpoints (ws://, wss://)
- Map upgrade endpoints and handshake process
- Identify message protocols (JSON, binary, custom)

### 2. Authentication & Authorization
- Test for missing authentication on WebSocket connections
- Test for authorization bypass after connection upgrade
- Check if HTTP session tokens are validated on upgrade
- Test for cross-origin WebSocket hijacking (CSWSH)

### 3. Input Validation
- Test for injection attacks through WebSocket messages
- Test for command injection in message handlers
- Test for XSS through WebSocket-delivered content
- Test for SQL injection through WebSocket message fields

### 4. Message Manipulation
- Test for message tampering (modify fields, add fields)
- Test for replay attacks
- Test for message sequence manipulation
- Test for race conditions in message processing

### 5. Denial of Service
- Test for resource exhaustion through rapid connections
- Test for large message handling
- Test for connection flooding

### 6. Information Disclosure
- Check for sensitive data in WebSocket messages
- Test for error messages leaking internals
- Monitor for unintended broadcast messages

```json
}
```
